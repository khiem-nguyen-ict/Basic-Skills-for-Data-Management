# Basic Skills for Data Management

A collection of materials, notebooks, and resources for developing foundational skills in data management and data science.

## Contents

- **Jupyter notebooks**: Introduction to Jupyter and interactive computing
- **Data files**: Sample datasets for practice and exploration
- **Materials**: Course notes, examples, and exercises

## Weekly Notebooks

- **week37/**: Jupyter Notebook introduction and interactive computing (`Jupyter_intro.ipynb`)
- **week38/**: Pandas Basics (`Pandas_Basics.ipynb`)
- **week39/**: NumPy basics, vectors, and matrices (`Numpy_basics,_vectors,_matrices.ipynb`)

Each week also includes an HTML export of the notebook for easy viewing without a Jupyter environment.

## Getting Started

1. Clone this repository
2. Install required dependencies (see individual notebook for details)
3. Explore the notebooks in the `week37/`, `week38/`, and `week39/` directories

## Tools & Technologies

- Jupyter Notebook
- Python
- Pandas
- NumPy
- Excel datasets
