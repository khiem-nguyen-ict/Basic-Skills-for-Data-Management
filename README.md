# Basic Skills for Data Management

A collection of materials, notebooks, and resources for developing foundational skills in data management and data science.

## Contents

- **Jupyter notebooks**: Introduction to Jupyter and interactive computing
- **Data files**: Sample datasets for practice and exploration
- **Materials**: Course notes, examples, and exercises

## Getting Started

1. Clone this repository
2. Install required dependencies (see individual notebook/README for details)
3. Explore the notebooks in the `week37/` directory

## Tools & Technologies

- Jupyter Notebook
- Python
- Pandas
- Excel datasets
